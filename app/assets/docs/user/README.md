# Caller's Compendium — User Guide

Welcome! This is the home for **Caller's Compendium** user documentation — the
guides that help you *use* the app, whether you are cataloguing dances, building a
program for Saturday's gig, or calling from the stage.

**Caller's Compendium** is a free, open-source dance organizer for contra-dance
callers, built for desktop, tablet, and phone. It keeps your collection of dances,
helps you assemble programs (set lists) for events, and gives you a large-print,
high-contrast **Perform mode** for calling live. It is **local-first**: your data
lives on your own device, the app works fully offline, and there is no account to
create and nothing to sign in to. You bring dances in from community sources or
your own files, put everything in *your own words* with a **dialect**, and take it
all with you with a single backup file.

These pages are written for **callers and dancers**. If you are a developer or
you want the design rationale behind a feature, head to the
[design docs](../design/) instead (see [Looking deeper](#looking-deeper) below).
